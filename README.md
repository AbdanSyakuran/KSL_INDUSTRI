# KSL_INDUSTRI
Kami melakukan analisis kesesuain lahan industri di kabupaten Karanganyar, Jawa Tengah. Kesesuaian ini di buat untuk mendukung pertumbuhan industri di kabupaten karanganyar dengan tetap memenuhi standar pembangunan di suatu lahan supaya tidak memberikan dampak negatif pada lahan dan lingkungan yang ada.
